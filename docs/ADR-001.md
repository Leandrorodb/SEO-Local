# ADR 001 — fundação incremental

Monorepo PNPM, React/TS, Fastify, PostgreSQL com migrations SQL revisadas e Drizzle. SQL explícito para RLS, bloqueios e fila. Legacy inalterado, fora do build.

OIDC Authorization Code + PKCE é alternativa equivalente a Firebase prevista na V3. JWKS, issuer, audience e algoritmo verificados; privilégios vêm do banco. MFA exige amr/acr assinado pelo IdP. Revogação de membership tem efeito na próxima requisição.

Fila PostgreSQL durável com transações/SKIP LOCKED é transporte inicial. Cloud Tasks pode entregar IDs ao mesmo worker. Permite testar isolamento e reservas antes da nuvem; Cloud Tasks/Scheduler não estão implantados.

CSS próprio com tokens e React Query reduz dependências; Tailwind/shadcn substituídos por componentes locais. PDFKit entrega PDFs em endpoint autenticado, sem URL pública. O logotipo PNG é validado e armazenado no PostgreSQL privado, com cópia no snapshot do relatório. Storage remoto permanece pendente.

PostgreSQL nativo via embedded-postgres só para testes/desenvolvimento; produção exige banco gerenciado e papéis distintos. Referências: https://www.postgresql.org/docs/current/ddl-rowsecurity.html e https://github.com/panva/jose.
