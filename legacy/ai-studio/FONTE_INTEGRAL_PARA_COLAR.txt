# NEXUS LOCAL RANK TRACKER — v1.1

Painel local para gerenciar fichas de empresas, termos por cluster, medições do Google Maps, resultados com trilha de evidência e feedbacks para WhatsApp. Sem uso de LLM e sem créditos de IA.

## Iniciar no Windows

1. Instale Node.js 22.16+ (recomendado Node 22 LTS ou superior) e Google Chrome.
2. Extraia todo o arquivo ZIP para uma pasta normal do seu computador.
3. Clique em `INICIAR_NEXUS.bat`. Na primeira execução, o sistema instala Playwright via npm (precisa internet apenas nessa etapa).
4. Acesse `http://127.0.0.1:4177`. Se não abrir automaticamente, cole esse endereço no Chrome.
5. É possível importar empresas em lote (colunas `nome;cidade;latitude;longitude;CID`) e depois importar termos ou gerar clusters por nicho.
6. As três fichas **Jares Pouso Alegre, Jares Três Corações e Jares Outlet**, com 84 termos, vêm cadastradas como exemplo operacional.
7. **Revise as coordenadas e o CID** de cada ficha antes de medir. Coordenadas de referência são aproximadas e não representam necessariamente a porta da loja.
8. Na aba Medições, escolha a empresa. Use `✦ Gerar clusters` para criar termos sugeridos sem IA, ou importe termos próprios. Em seguida clique em `Medir pesquisas`. Use P1 para uma coleta curta ou Todos para os demais termos.
9. Uma janela do Chrome é aberta para o Google Maps. Não feche enquanto estiver medindo.
10. Revise os resultados `Revisar` e abra as capturas de tela; confirme apenas quando identidade e posição orgânica forem claras. Depois gere o feedback e copie para WhatsApp.

No Linux/macOS: `npm install` seguido de `npm start`. O Chrome precisa estar instalado no computador ou você deve adaptar `channel:'chrome'` no serviço de coleta.

## Pastas e arquitetura

- `src/db.js`: banco SQLite local, migração inicial e dados.
- `src/server.js`: API HTTP protegida em `127.0.0.1`.
- `src/services/measurement.js`: fila sequencial, navegador Playwright, geolocalização e evidências.
- `src/services/report.js`: geração de feedback e CSV seguro.
- `public/`: interface web responsiva sem dependências frontend.
- `data/jares-seed.json`: matriz inicial das 3 unidades (84 pesquisas).
- `local-data/nexus.sqlite`: banco criado automaticamente **fora do código-fonte**.
- `local-data/evidence`: prints e perfil temporário do Chrome.

**Backup:** copie a pasta `local-data` com o programa fechado. Para manter histórico, não apague essa pasta quando atualizar o sistema.

## Regras de medição

- A consulta é feita a partir de coordenadas de referência por unidade; não existe garantia de mesma posição para toda uma cidade.
- Se o URL de um resultado contém o CID da ficha, é classificado como `Confirmado` (observe que a interface do Google pode alterar os links).
- Correspondências apenas por nome entram como `Revisar`. **Não** aparecem como conquista em relatórios antes de validação humana.
- Uma abertura direta da ficha sem feed ordenado não é interpretada como Top 1.
- Resultados sinalizados como patrocinados não são contabilizados intencionalmente. Mudanças na marcação da interface podem exigir revisão dos prints.
- Se o Google mostrar verificação humana/CAPTCHA, a execução é interrompida. **Não** usa evasão de bloqueios, proxies, rotação de identidades ou quebra de CAPTCHA.
- A coleta é de baixa frequência, sequencial, acionada pelo usuário. Consulte as condições do serviço antes de usar automação em larga escala; para escala comercial, considere uma fonte licenciada de dados de ranking.
- O sistema **não** altera o Perfil da Empresa no Google e **não** envia WhatsApp automaticamente.

## Problemas comuns

**O botão de medir não abre o Chrome:** confira se Google Chrome está instalado, se a tela está desbloqueada e se o terminal mostra algum erro. Use `npm install` para instalar Playwright.

**Aparece `REVIEW` (revisar):** a URL do resultado não provou automaticamente o identificador da ficha. Abra o print e confira antes de confirmar. O rank só será reportado após essa etapa.

**Aparece `NO_LIST`:** o Google Maps não exibiu uma lista comparável ou houve redirecionamento direto. Isso não é evidência de posição 1.

**Aparece `BLOCKED`:** o Google solicitou verificação humana. Interrompa a automação e consulte o serviço; não tente burlar a verificação.

**Não aparece nenhuma posição mesmo com loja presente no Google:** pode haver diferença no nome, no CID, endereço, scroll, sessão do Maps ou localização da busca. Verifique o print antes de confiar em resultados.

## Verificação técnica

`npm test` executa testes de segurança de posição, confirmação por CID, caso sem feed e banco local.

O sistema é um **MVP operacional**, não um SaaS multiusuário pronto para comercialização. Não possui autenticação remota, RBAC, multi-tenant e telemetria de produção. Fica restrito ao `localhost`, com banco local e sem expor dados a terceiros. Para vender como SaaS, separar API, autenticação, isolamento por `orgId`, jobs persistentes, storage privado, auditoria de acessos, limites por tenant e contratação de fonte licenciada de ranking.

## Novidade da v1.1: importar o resultado.zip sem gastar tokens

O primeiro piloto foi executado pelo medidor independente, que exportou `resultado.zip` contendo `MEDICOES_JARES.csv`, imagens e listas de resultados.

1. **Antes de atualizar:** feche a janela de terminal do Nexus e faça backup da pasta `local-data` da versão antiga.
2. Extraia a **v1.1** na pasta onde você deseja manter o sistema. Se preferir instalar em outra pasta, copie sua pasta antiga `local-data` para dentro da nova instalação antes de iniciar o programa.
3. Coloque o `resultado.zip` (gerado pelo medidor) ao lado de `IMPORTAR_RESULTADO.bat`, **ou arraste esse ZIP diretamente para cima do arquivo `.bat`**.
4. Execute `IMPORTAR_RESULTADO.bat`. Uma mesma planilha não será importada duas vezes. O ZIP pode ser grande porque contém prints; o programa preserva as imagens dentro de `local-data/evidence`.
5. Execute `INICIAR_NEXUS.bat` e veja os resultados em **Medições → empresa → histórico de auditorias**. As coletas importadas aparecem identificadas como **Importado**. Em **Feedbacks**, copie os termos com evidência verificada.

**Comando alternativo (terminal):** `node scripts/import-result.js "C:\\caminho\\resultado.zip"`. Também aceita a pasta extraída que contém `MEDICOES_JARES.csv` e `prints`.

**Resultados do piloto de referência:** 84 pesquisas, das quais 60 tiveram posição concordante com o CID nos arquivos de resultados; as demais 24 não foram automaticamente anunciadas como colocação confirmada (10 para revisão e 14 sem posição comparável/localização conclusiva). Isso confirma a integridade da importação dos arquivos fornecidos, **não** é garantia de precisão geográfica em toda a cidade nem de validade de uma captura patrocinada ou desatualizada. Confira os prints antes do envio.

**Se você atualizar sobre uma versão antiga**, mantenha `local-data`: é ali que ficam os dados reais. Não copie a pasta `local-data` de uma instalação nova por cima da antiga. O SQLite recebe uma migração compatível na primeira inicialização da v1.1. Não execute importação simultaneamente a outra coleta.

**Limitação desta versão:** a importação em lote suporta o formato do medidor Jares (`MEDICOES_JARES.csv`). Para outros scripts, será necessário adaptar um importador ou seguir uma interface CSV padronizada em uma versão futura.

# Arquitetura — Nexus Local Rank Tracker

## Objetivo e limites

Aplicação local, mono-operador e de baixo custo para uma carteira de SEO local. Diferencia **sugestão de palavras-chave**, **coleta de resultados** e **verificação de posições**. Não garante geogrid nem substitui uma fonte licenciada de SERP para uso em escala comercial.

## Fluxo de dados

```
Cadastro de empresa + CID + coordenadas
        |
Clusters/termos P1-P3 (digitados, importados ou sugeridos sem IA)
        |
Fila persistida SQLite (1 navegação por vez)
        |
Chrome Playwright em janela visível / centro geográfico escolhido
        |
Resultado orgânico ordenado + nome + URL + detalhe + screenshot
        |
Identificação por CID => VERIFICADO
Identificação somente por nome => REVISÃO HUMANA
Sem lista ou bloqueio => SEM MEDIÇÃO COMPROVADA
        |
Histórico por run/termo e CSV
        |
Feedback WhatsApp com APENAS posições verificadas
```

## Separação de responsabilidades

- UI: `public/index.html`, `public/app.js`, `public/styles.css`.
- API e regras de acesso local: `src/server.js`.
- Persistência e esquema: `src/db.js` (`node:sqlite`).
- Ingestão de resultados e fila: `src/services/measurement.js`.
- Gerador determinístico de clusters: `src/services/keywords.js`.
- Feedbacks/exportação: `src/services/report.js`.
- Validação automatizada: `tests/measurement.test.js`.

## Critérios de qualidade

- Não confiar em nomes repetidos para classificar automaticamente.
- Ignorar, tanto quanto possível, inserções de anúncios; inspecionar evidências quando layout mudar.
- Posicionamento geográfico deve ter ponto e timestamp claros.
- Um acesso direto à ficha não é evidência de posição 1.
- Capturas e listas observadas ficam no armazenamento local.
- API escuta apenas em `127.0.0.1`; não expor porta na internet.
- Nenhuma mensagem de WhatsApp é enviada sem o usuário copiar.

## Evolução para SaaS multi-tenant

Quando o motor local estiver validado em uso real:

1. Isolar API REST e interface React/TypeScript; validar o contrato com Zod.
2. Migrar SQLite para PostgreSQL e incluir `org_id` em tabelas com políticas RLS.
3. Adicionar autenticação Firebase/Google e RBAC (admin, consultor, cliente).
4. Salvar jobs com idempotência em Redis/BullMQ e workers separados.
5. Usar storage privado de evidências por organização, com URLs temporárias.
6. Controlar custos por tenant, limites de consultas, consentimento e retenção LGPD.
7. Para verificação regular em grande escala, contratar fonte licenciada de dados de posição geográfica e garantir conformidade com termos da plataforma.
8. Adicionar testes E2E, métricas, alertas, monitoramento e deploy com backups/versionamento.

Não subir esta versão local diretamente em hosting público: ela **não possui autenticação nem isolamento multi-tenant**.

## v1.1 — Ingestão auditável de medições existentes

- `scripts/import-result.js`: importação local por CLI ou `.bat`, sem expor upload de arquivos por rede.
- `src/services/import.js`: parser CSV, leitura de ZIP local, normalização de empresas, correspondência exata de pesquisas e clusters, verificação independente de CID no JSON da lista, cópia de evidências e transação SQLite.
- `runs.source`: indica `LIVE` para coletas no painel e `IMPORT` para dados de medidores externos. Migração adiciona a coluna em bases v1 existentes sem apagar histórico.
- `imported_batches`: hash SHA-256 do CSV para impedir duplicação na mesma base.
- Políticas: posição importada só vira `VERIFIED` quando o CID encontrado no JSON corresponde à empresa e à posição da linha do CSV, descontando anúncios sinalizados. Nos demais casos a posição candidata vai para `REVIEW` e não aparece como conquista confirmada.
- Limitação: o processo de importação específico de `MEDICOES_JARES.csv` exige empresas previamente cadastradas com mesmo nome e termos/cluster previamente incluídos. A fila de coleta original continua separada.

 const res=await fetch(endpoint,{...options,headers:{'Content-Type':'application/json',...(options.headers||{})}});

async function loadSelected(){
 if(!state.selectedId){state.terms=[];state.runs=[];state.run=null;state.previousRun=null;state.report=null;return;}
 const id=state.selectedId;
 const [terms,runs,report]=await Promise.all([
  request(`/api/companies/${id}/terms`),request(`/api/companies/${id}/runs`),request(`/api/companies/${id}/feedback`)]);
 state.terms=terms;state.runs=runs;state.report=report;
 if(!runs.some(r=>r.id===state.selectedRunId))state.selectedRunId=runs[0]?.id||null;
 const selectedIndex=runs.findIndex(r=>r.id===state.selectedRunId);
 const prior=selectedIndex>=0?runs[selectedIndex+1]:null;
 const [current,previous]=await Promise.all([
   state.selectedRunId?request(`/api/runs/${state.selectedRunId}`):Promise.resolve(null),
   prior?request(`/api/runs/${prior.id}`):Promise.resolve(null)
 ]);
 state.run=current;state.previousRun=previous;
}

function send(res,status,data,contentType='application/json; charset=utf-8'){

async function parseBody(req){
 let chunks=[],bytes=0;
 for await(const chunk of req){bytes+=chunk.length;if(bytes>1024*1024)throw Object.assign(Error('Payload acima de 1 MB'),{http:413});chunks.push(chunk);}
 try{return JSON.parse(Buffer.concat(chunks).toString('utf8')||'{}');}catch{throw Object.assign(Error('JSON inválido'),{http:400});}
}
function requiredText(str,max=200){if(typeof str!=='string'||!str.trim()||str.trim().length>max)throw Object.assign(Error('Texto obrigatório ou grande demais'),{http:400});return str.trim();}
function idOf(x){const n=Number(x);if(!Number.isSafeInteger(n)||n<1)throw Object.assign(Error('ID inválido'),{http:400});return n;}
function companyPayload(body){
 const name=requiredText(body.name,160),city=requiredText(body.city,120);
 const latitude=Number(body.latitude),longitude=Number(body.longitude);
 if(!Number.isFinite(latitude)||Math.abs(latitude)>90||!Number.isFinite(longitude)||Math.abs(longitude)>180)throw Object.assign(Error('Latitude/longitude inválidas'),{http:400});
 const cid=String(body.cid||'').replace(/^0x/i,'').trim().toLowerCase();
 if(cid&&!/^[0-9a-f]{8,20}$/.test(cid))throw Object.assign(Error('CID deve ser hexadecimal'),{http:400});
 const mapsUrl=String(body.maps_url||'').trim();
 if(mapsUrl && (mapsUrl.length>1500||!/^https:\/\/(www\.)?google\.com\/maps\//i.test(mapsUrl)))throw Object.assign(Error('URL deve ser HTTPS do Google Maps'),{http:400});
 return [name,city,latitude,longitude,cid,mapsUrl];
}
function termPayload(body){
 const query=requiredText(body.query,240),cluster=requiredText(body.cluster||'Geral',90),priority=body.priority||'P2';
 if(!['P1','P2','P3'].includes(priority))throw Object.assign(Error('Prioridade inválida'),{http:400});
 return [query,cluster,priority];
}

   if(method==='PUT'){const fields=companyPayload(await parseBody(req));const info=db.prepare('UPDATE companies SET name=?,city=?,latitude=?,longitude=?,cid=?,maps_url=? WHERE id=?').run(...fields,companyId);return info.changes?send(res,200,getCompany(db,companyId)):error(res,404,'Empresa não encontrada');}}
 m=p.match(/^\/api\/companies\/(\d+)\/terms$/);
 if(m){const companyId=idOf(m[1]);if(!getCompany(db,companyId))return error(res,404,'Empresa não encontrada');

export function insertSeed(db, records) {

  const add = db.prepare('INSERT INTO companies(name,city,latitude,longitude,cid,maps_url) VALUES (?,?,?,?,?,?)');
  const addTerm = db.prepare('INSERT OR IGNORE INTO terms(company_id, query, cluster, priority) VALUES (?,?,?,?)');

  try {
    for (const shop of records) {
      const result=add.run(shop.unit, shop.city, shop.lat, shop.lon, shop.cid||'', shop.mapsUrl||'');
      const id=Number(result.lastInsertRowid);
      for (const term of shop.terms) addTerm.run(id, term.term, term.cluster, term.priority);
    }

  } catch (error) { db.exec('ROLLBACK'); throw error; }
}

export function isDirectCidMatch(company,result){
  const cid=String(company.cid||'').toLowerCase().replace(/^0x/,'');
  if(!cid || !/^[0-9a-f]{8,20}$/.test(cid))return false;
  const link=String(result.url||'').toLowerCase();
  // Target feature ID must be present as full 0x-encoded field, not a substring of a name.
  return link.includes(':0x'+cid) || new RegExp(`(?:[?&]cid=)${BigInt('0x'+cid).toString()}(?:&|$)`).test(link);
}
export function findCandidate(company,results){
  const cidIndex=results.findIndex(x=>isDirectCidMatch(company,x));
  if(cidIndex>=0)return {confidence:'CID', position:cidIndex+1, matched:results[cidIndex]};
  const full=normalize(company.name);
  const short=normalize(company.name.split(/[—|]/)[0]);
  const aliases=[...new Set([full,short])].filter(x=>x.length>=5);
  const matched=results.map((r,i)=>({r,i})).filter(({r})=>{
    const name=normalize(r.name),raw=normalize(r.detail);
    const aliasMatch=aliases.some(a=>name.includes(a));
    const outletWanted=full.includes('outlet');
    return aliasMatch && (outletWanted || !name.includes('outlet')) &&
      (raw.includes(normalize(company.city)) || name.includes(normalize(company.city)));
  });
  // Ambiguous name matches are never promoted to verified ranking automatically.
  if(matched.length===1)return {confidence:'NAME_ONLY',position:matched[0].i+1,matched:matched[0].r};
  return {confidence:'NONE',position:null,matched:null};
}
export function evaluateObserved(company,results,feedLoaded){
  if(!feedLoaded)return {status:'NO_LIST',position:null,candidatePosition:null,confidence:'NONE'};
  const organic=results.filter(x=>!x.promoted);
  const candidate=findCandidate(company,organic);
  if(candidate.confidence==='CID')return {status:'VERIFIED',position:candidate.position,candidatePosition:null,confidence:'CID'};
  if(candidate.confidence==='NAME_ONLY')return {status:'REVIEW',position:null,candidatePosition:candidate.position,confidence:'NAME_ONLY'};
  return {status:organic.length>=20?'NOT_FOUND':'REVIEW',position:null,candidatePosition:null,confidence:'NONE'};
}

}

  }

export function parseCsv(text){
  const rows=[];let row=[],value='',quoted=false;
  const input=String(text).replace(/^\uFEFF/,'');
  for(let i=0;i<input.length;i++){
    const ch=input[i];
    if(quoted){if(ch==='"' && input[i+1]==='"'){value+='"';i++;}else if(ch==='"')quoted=false;else value+=ch;}
    else if(ch==='"')quoted=true;
    else if(ch===';'){row.push(value);value='';}
    else if(ch==='\r'||ch==='\n'){
      if(ch==='\r'&&input[i+1]==='\n')i++;
      row.push(value);value='';if(row.some(c=>c!==''))rows.push(row);row=[];
    }else value+=ch;
  }
  if(quoted)throw Error('CSV com aspas nao terminadas');
  if(value!==''||row.length){row.push(value);rows.push(row);}
  if(rows.length<2)throw Error('CSV vazio ou sem cabecalho');
  const headers=rows.shift();
  return rows.map((r,index)=>{
    if(r.length!==headers.length)throw Error(`CSV linha ${index+2}: numero de colunas invalido`);
    return Object.fromEntries(headers.map((h,i)=>[h,r[i]]));
  });
}

function command(bin,args){return execFileSync(bin,args,{encoding:'utf8',stdio:['ignore','pipe','pipe'],timeout:90_000,maxBuffer:10*1024*1024});}
function openInput(src){
  const p=path.resolve(src);
  if(!fs.existsSync(p))throw Error('Pasta ou arquivo nao encontrado: '+p);
  if(fs.statSync(p).isDirectory())return {root:p,cleanup:()=>{}};
  if(!p.toLowerCase().endsWith('.zip'))throw Error('Use um arquivo .zip ou a pasta extraida');
  const tmp=fs.mkdtempSync(path.join(os.tmpdir(),'nexus-import-'));
  try{
    let names;
    let method='tar';
    try{names=command('tar',['-tf',p]).split(/\r?\n/).filter(Boolean);}catch{
      method='unzip';names=command('unzip',['-Z1',p]).split(/\r?\n/).filter(Boolean);
    }
    if(names.some(name=>/^(?:[\\/]|[a-z]:)/i.test(name)||name.replaceAll('\\','/').split('/').includes('..')))
      throw Error('O ZIP contem caminhos inseguros');
    if(names.length>6000)throw Error('O ZIP contem arquivos demais');
    if(method==='tar')command('tar',['-xf',p,'-C',tmp]);
    else command('unzip',['-oq',p,'-d',tmp]);
    return {root:tmp,cleanup:()=>fs.rmSync(tmp,{recursive:true,force:true})};
  }catch(e){fs.rmSync(tmp,{recursive:true,force:true});throw e;}
}
function findReportDir(root){
  const dirs=[root,path.join(root,'resultado')];
  return dirs.find(d=>fs.existsSync(path.join(d,'MEDICOES_JARES.csv')));
}
function evidencePath(base,relative){
  if(typeof relative!=='string'||!relative.trim())return null;
  const normalized=relative.replaceAll('\\','/');
  const clean=path.normalize(normalized);
  if(path.isAbsolute(clean)||clean.split(path.sep).includes('..')||/^[a-z]:/i.test(clean))throw Error('Caminho de evidencia inseguro');
  const absolute=path.resolve(base,clean);
  if(!absolute.startsWith(base+path.sep))throw Error('Evidencia fora da pasta importada');
  return absolute;
}
function parseBrazilDate(value){
  const m=/^(\d{2})\/(\d{2})\/(\d{4}),?\s+(\d{2}):(\d{2}):(\d{2})$/.exec(value||'');
  if(!m)throw Error('Data da medicao invalida: '+value);
  const [_,day,month,year,hour,min,sec]=m;
  const d=new Date(`${year}-${month}-${day}T${hour}:${min}:${sec}-03:00`);
  if(Number.isNaN(d.getTime()))throw Error('Data invalida: '+value);
  return d.toISOString();
}
/** Import data from the external free Jares measurement script. CID corroboration is required
 * before a row can become VERIFIED, regardless of the reported numerical position. */
export function importLegacyJares(db,source,outputDir){
 const input=openInput(source);const written=[];
 try{
  const root=findReportDir(input.root);
  if(!root)throw Error('Nao encontrei MEDICOES_JARES.csv no ZIP ou pasta');
  const csvBuffer=fs.readFileSync(path.join(root,'MEDICOES_JARES.csv'));
  const digest=crypto.createHash('sha256').update(csvBuffer).digest('hex');
  const existing=db.prepare('SELECT 1 FROM imported_batches WHERE digest=?').get(digest);
  if(existing)return {duplicate:true,imported:0};
  const rows=parseCsv(csvBuffer.toString('utf8'));
  if(rows.length>2000)throw Error('Limite de 2000 buscas por importacao');
  const headers=['Unidade','Cluster','Prioridade','Termo','Posição observada','Status','Data/hora','Busca Maps','Print'];
  if(!rows.every(r=>headers.every(h=>typeof r[h]==='string')))throw Error('O arquivo CSV nao tem o formato esperado');
  const companies=db.prepare('SELECT * FROM companies').all();
  const lookups=new Map(companies.map(c=>[normalize(c.name),c]));
  const groups=new Map();
  for(const r of rows){const key=normalize(r.Unidade);if(!lookups.has(key))throw Error('Empresa nao cadastrada: '+r.Unidade);
    if(!groups.has(key))groups.set(key,[]);groups.get(key).push(r);
  }
  const stamp=new Date().toISOString(),summary=[];
  db.exec('BEGIN');
  try{
   for(const [key,items] of groups){
    const company=lookups.get(key),terms=db.prepare('SELECT * FROM terms WHERE company_id=?').all(company.id);
    const termMap=new Map(terms.map(t=>[normalize(t.query),t]));
    const run=Number(db.prepare("INSERT INTO runs(company_id,mode,status,total,completed,created_at,started_at,ended_at,message,source) VALUES(?,'all','COMPLETE',?,?,?,?,?,?,'IMPORT')").run(company.id,items.length,items.length,stamp,stamp,stamp,'Auditoria importada; posicoes validadas por CID onde possivel').lastInsertRowid);
    const dir=path.join(outputDir,`run-${run}`);fs.mkdirSync(dir,{recursive:true});
    let verified=0,review=0;
    for(const row of items){
     const term=termMap.get(normalize(row.Termo));if(!term)throw Error(`Termo nao cadastrado para ${company.name}: ${row.Termo}`);
     if(normalize(term.cluster)!==normalize(row.Cluster))throw Error('Cluster divergente: '+row.Termo);
     const value=row['Posição observada'].trim();const observed=value?Number(value):null;
     if(value && (!Number.isInteger(observed)||observed<1||observed>500))throw Error('Posicao invalida: '+row.Termo);
     const date=parseBrazilDate(row['Data/hora']);
     const url=row['Busca Maps'];if(url && !/^https:\/\/www\.google\.com\/maps\//i.test(url))throw Error('Busca Maps invalida');
     const png=evidencePath(root,row.Print),jsonPath=png?png.replace(/\.png$/i,'_lista.json'):null;
     const results=jsonPath&&fs.existsSync(jsonPath)?JSON.parse(fs.readFileSync(jsonPath,'utf8')):[];
     if(!Array.isArray(results)||results.length>300)throw Error('Lista de resultados invalida');
     const check=evaluateObserved(company,results,results.length>0);
     let status='NO_LIST',position=null,candidate=null,confidence='NONE',note='Importado sem lista de resultados comparavel';
     if(observed!==null){
       if(check.status==='VERIFIED' && check.position===observed){status='VERIFIED';position=observed;confidence='CID';note='Posicao importada e conferida com CID da ficha nos resultados organicos';verified++;}
       else{status='REVIEW';candidate=observed;confidence='CSV_ONLY';note='Posicao observada no CSV ainda nao validada por CID; revisar antes de publicar';review++;}
     } else if(/30 primeiros/i.test(row.Status||'')){status='NOT_FOUND';note='Nao localizada no conjunto limitado de resultados observados';}
     else if(/sem lista/i.test(row.Status||'')){status='NO_LIST';note='A consulta nao retornou lista comparavel';}
     else {status='REVIEW';note='Busca inconclusiva; sem posicao numerica para confirmar';review++;}
     let screenshot='';
     if(png && fs.existsSync(png)){
       if(fs.statSync(png).size>8*1024*1024)throw Error('Print maior que 8MB');
       const safeName=`${term.id}_${path.basename(png).replace(/[^a-zA-Z0-9_.-]/g,'_')}`;
       const target=path.join(dir,safeName);fs.copyFileSync(png,target);written.push(target);screenshot=`run-${run}/${safeName}`;
     }
     db.prepare(`INSERT INTO measurements(run_id,term_id,status,position,candidate_position,confidence,screenshot,search_url,results_json,observed_count,measured_at,review_note)
      VALUES(?,?,?,?,?,?,?,?,?,?,?,?)`).run(run,term.id,status,position,candidate,confidence,screenshot,url,JSON.stringify(results),results.filter(x=>!x.promoted).length,date,note);
    }
    summary.push({company:company.name,runId:run,total:items.length,verified,review});
   }
   db.prepare('INSERT INTO imported_batches(digest,created_at,source_name) VALUES(?,?,?)').run(digest,stamp,path.basename(source).slice(0,200));
   db.exec('COMMIT');
  }catch(e){db.exec('ROLLBACK');for(const f of written)try{fs.rmSync(f,{force:true});}catch{}throw e;}
  return {duplicate:false,imported:rows.length,companies:summary};
 }finally{input.cleanup();}
}

export function suggestKeywords({city,niche,products=[]}){

 const location=norm(city).replace(/,\s*(MG|SP|RJ|ES|BA|PR|SC|RS|GO|DF|RO|AC|AM|RR|PA|TO|AP|MA|PI|CE|RN|PB|PE|AL|SE|MT|MS)\b/i,'');
 if(!location)return [];
 const terms=[];
 for(const [cluster,phrases] of Object.entries(base.clusters)){
  phrases.forEach((phrase,i)=>terms.push({query:`${phrase} em ${location}`,cluster,priority:i<2?'P1':'P2'}));
 }
 for(const product of products){
  const name=norm(product).slice(0,90);
  if(!name)continue;
  terms.push({query:`${name} em ${location}`,cluster:'Produtos e serviços informados',priority:'P1'});
  terms.push({query:`comprar ${name} em ${location}`,cluster:'Produtos e serviços informados',priority:'P2'});
 }
 const existing=new Set();
 return terms.filter(x=>{const k=x.query.toLowerCase();if(existing.has(k))return false;existing.add(k);return true;}).slice(0,100);
}

import { getCompany, getMeasurements, getLatestRun } from '../db.js';
const order = ['VERIFIED','REVIEW','NOT_FOUND','NO_LIST','BLOCKED','ERROR','PENDING'];
export function buildReport(db, companyId) {
  const company=getCompany(db,companyId);
  if(!company) return null;
  const run=getLatestRun(db,companyId);
  const rows=run?getMeasurements(db,run.id):[];
  const verified=rows.filter(r=>r.status==='VERIFIED' && Number.isInteger(r.position));
  const review=rows.filter(r=>r.status==='REVIEW');
  const group=n=>verified.filter(r=>r.position===n).map(r=>r.query);
  const top5=verified.filter(r=>r.position<=5).length;
  const top3=verified.filter(r=>r.position<=3).length;
  const clusters=[...new Set(rows.map(r=>r.cluster))];
  const parts=[`📊 *NEXUS | FEEDBACK DE MEDIÇÃO — ${company.name.toUpperCase()}*`,
    'Bom dia, pessoal! Tudo bem? 😊',
    'Compartilhamos o acompanhamento das pesquisas comerciais da empresa no Google Maps, considerando a localização de referência utilizada na auditoria.'];
  if (!run) parts.push('📌 *Ainda não existe uma medição concluída para esta ficha.*');
  else {
    const section=(pos,emoji,label)=>{const arr=group(pos);if(arr.length)parts.push(`${emoji} *${label}*\n${arr.map(t=>`${emoji} ${t}`).join('\n')}`);};
    section(1,'🥇','PRIMEIROS LUGARES CONFIRMADOS');
    section(2,'🥈','SEGUNDOS LUGARES CONFIRMADOS');
    section(3,'🥉','TERCEIROS LUGARES CONFIRMADOS');
    const fourFive=verified.filter(r=>r.position===4||r.position===5);
    if(fourFive.length)parts.push(`📈 *POSIÇÕES 4 E 5*\n${fourFive.map(r=>`• ${r.query} — ${r.position}º`).join('\n')}`);
    parts.push(`📊 *RESUMO DA AUDITORIA*\n• ${rows.length} pesquisas incluídas\n• ${verified.length} posições verificadas\n• ${top3} termos no Top 3\n• ${top5} termos no Top 5\n• ${review.length} resultados aguardando revisão`);
    if(review.length)parts.push('🔍 *EM CONFERÊNCIA*\nHá resultados potencialmente relacionados à empresa que ainda exigem validação da ficha e da posição antes de qualquer anúncio.');
    if(!verified.length)parts.push('Até esta coleta, não foi possível comprovar posições orgânicas com segurança. Seguimos em conferência; isso não significa ausência da empresa nas buscas.');
    if(clusters.length)parts.push(`🎯 *CLUSTERS MONITORADOS*\n${clusters.map((x,i)=>`${i+1}. ${x}`).join('\n')}`);
  }
  parts.push('As posições correspondem ao momento e à localização da coleta e podem variar conforme o dispositivo, o horário e o histórico de busca. Seguimos trabalhando para ampliar a presença da empresa nas pesquisas mais relevantes. 🚀🤝');
  return {company, run, measurements:rows, verifiedCount:verified.length, reviewCount:review.length, text:parts.join('\n\n')};
}
export function csv(rows){
  const escape=value=>{
    let str=String(value??'');
    // CSV formula injection prevention for Excel/Sheets.
    if(/^[\s]*[=+@\-]/.test(str))str="'"+str;
    return '"'+str.replaceAll('"','""')+'"';
  };
  const header=['Termo','Cluster','Prioridade','Posição confirmada','Posição candidata','Status','Data da medição','URL de pesquisa','Print','Quantidade observada','Nota de revisão'];
  const lines=rows.map(r=>[r.query,r.cluster,r.priority,r.position??'',r.candidate_position??'',r.status,r.measured_at??'',r.search_url,r.screenshot,r.observed_count,r.review_note]);
  return '\ufeff'+[header,...lines].map(a=>a.map(escape).join(';')).join('\r\n');
}

import test from 'node:test';
import assert from 'node:assert/strict';
import fs from 'node:fs';

test('CSV parser supports quotes, embedded newlines and semicolons',()=>{
 const csv='"Unidade";"Termo"\r\n"Jares";"sofa; com \""frase\""\nextra"\r\n';
 assert.deepEqual(parseCsv(csv),[{Unidade:'Jares',Termo:'sofa; com "frase"\nextra'}]);
});

test('imported CSV requires CID verification and prevents duplicates',()=>{
 const dir=fs.mkdtempSync(path.join(os.tmpdir(),'nexus-csv-import-'));
 const db=createDb(path.join(dir,'app.sqlite'));
 try {
  const fixture=path.join(dir,'resultado'),prints=path.join(fixture,'prints'),out=path.join(dir,'evidence');
  fs.mkdirSync(prints,{recursive:true});fs.mkdirSync(out,{recursive:true});
  const name='Jares Móveis — Pouso Alegre',cid='d16aefdbdee3d709';
  insertSeed(db,[{unit:name,city:'Pouso Alegre',lat:-22.23,lon:-45.933,cid,terms:[
    {term:'loja de móveis em Pouso Alegre',cluster:'Loja de móveis',priority:'P1'},
    {term:'comprar móveis em Pouso Alegre',cluster:'Loja de móveis',priority:'P1'}]}]);
  const rows=[['loja de móveis em Pouso Alegre',2,'v1'],['comprar móveis em Pouso Alegre',1,'v2']];
  for(const [term,rank,prefix] of rows){
   fs.writeFileSync(path.join(prints,prefix+'.png'),Buffer.from([137,80,78,71,13,10,26,10]));
   const hit={name:'Jares Móveis',url:`https://google.com/maps/place/Teste/data=!4m2!3m1!1s0x0:0x${prefix==='v1'?cid:'deadbeef12345678'}`,promoted:false};
   fs.writeFileSync(path.join(prints,prefix+'_lista.json'),JSON.stringify(prefix==='v1'?[{name:'Outro',url:'https://google.com/maps/place/outro',promoted:false},hit]:[hit]));
  }
  const columns=['Unidade','Cidade','Cluster','Prioridade','Termo','Posição observada','Status','Data/hora','Local de referência','Resultados orgânicos capturados','Busca Maps','Print','Concorrentes até 10'];
  const record=(term,rank,id)=>[name,'Pouso Alegre','Loja de móveis','P1',term,String(rank),'Posição observada','30/10/2026, 11:12:56','-22.23,-45.933','2','https://www.google.com/maps/search/teste',`prints\\${id}.png`,''] .map(v=>'"'+v.replaceAll('"','""')+'"').join(';');
  fs.writeFileSync(path.join(fixture,'MEDICOES_JARES.csv'),columns.map(v=>'"'+v+'"').join(';')+'\n'+record(rows[0][0],2,'v1')+'\n'+record(rows[1][0],1,'v2')+'\n');
  const first=importLegacyJares(db,fixture,out);
  assert.equal(first.imported,2);assert.equal(first.companies[0].verified,1);assert.equal(first.companies[0].review,1);
  assert.equal(importLegacyJares(db,fixture,out).duplicate,true);
  const measurements=db.prepare('SELECT status,position,candidate_position,confidence,screenshot FROM measurements ORDER BY id').all();
  assert.deepEqual(measurements.map(r=>r.status),['VERIFIED','REVIEW']);
